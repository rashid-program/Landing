# CONTEXT.md — MathX

Лендинг репетитора по математике: подготовка к ЕГЭ (профиль/база) и ОГЭ,
мини-группы до 6 человек. Аудитория — родители школьников и взрослые ученики, Россия.

## Текущее состояние

Актуальный и единственный дизайн — **v3** (светлая тема, `public/site-v3.css`).
Старый тёмный дизайн v1 и папка-песочница `sandbox-mathx-v2/` удалены 15.09.2026:
v3 был утверждён владельцем и переехал в корень проекта.

Вместе со старым дизайном удалена админка (`admin.js`, `admin-data.json`,
роуты `/api/texts`, режим «Редактировать» с `data-editable`). В v3 её нет —
тексты правятся прямо в `public/index.html`.

## Запуск

```
cd server && npm start     # http://localhost:3008
cd server && npm test      # тесты приватности и статистики (11 штук)

# панель статистики: токен задаётся при запуске
STATS_TOKEN=любой-длинный-секрет npm start
# затем открыть http://localhost:3008/stats и ввести токен в форму
node screenshot.mjs http://localhost:3008 имя   # скриншот в ./temporary screenshots/
```

## Что важно знать перед продом

1. **Приём заявок сейчас отключён.** Сервер стартует с `Privacy-first lead
   collection: disabled` и будет молчать, пока в `.env` не заданы
   `PRIMARY_LEAD_WEBHOOK_URL`, `DATA_OPERATOR_ID`, `CONSENT_VERSION` и
   `PRIMARY_STORAGE_CONFIRMED=true`. Это сделано намеренно: по 152-ФЗ
   персональные данные россиян должны сначала записываться в РФ. Telegram
   получает только случайный ID заявки, без имени и телефона.
2. **В `public/index.html` стоит `<meta name="robots" content="noindex, nofollow">`** —
   наследие песочницы. Снять перед публикацией, иначе сайт не попадёт в поиск.
3. **Аналитика своя, безкуковая** — см. `docs/ANALYTICS.md`. Панель открывается
   по адресу `/stats`, токен вводится в форму и уходит заголовком; задаётся
   переменной `STATS_TOKEN`, и пока она пуста, `/api/stats` отдаёт 404. Внешние счётчики (Яндекс.Метрика) пока не
   подключены: по `docs/LEGAL_152FZ.md` они требуют баннера согласия, а также
   правки CSP в `server.js` — домены счётчика нужно разрешить явно.
4. Контакты в футере — плейсхолдеры, реальные не подтверждены (см. `docs/DEFERRED_TASKS.md`).

## Рабочие правила

Не выдумывать факты о репетиторе: образование, стаж, баллы учеников, гарантии
и контакты берутся только от владельца. Недостающее — в `docs/DEFERRED_TASKS.md`.
