# Админ-панель MathX — Руководство

## Обзор системы

Система редактирования контента интегрирована прямо в лендинг. Администратор может редактировать текст на месте без отдельной административной страницы.

## Как это работает

### 1. Авторизация

- На главной странице справа сверху в хедере кнопка **«Редактировать»**
- Кнопка выглядит блеклой, пока администратор не авторизирован
- При нажатии на кнопку появляется модальное окно авторизации
- Пароль администратора: `mathx2026`

### 2. Режим редактирования

После успешной авторизации:

- Кнопка «Редактировать» становится активной (яркой)
- Нажимаем кнопку ещё раз, чтобы включить режим редактирования
- Кнопка меняет текст на «Готово»
- На странице появляется голубой фон вокруг всех редактируемых элементов
- Рядом с каждым текстовым элементом появляется значок карандаша ✎

### 3. Редактирование текста

- Наводимся на редактируемый элемент
- Нажимаем на иконку карандаша ✎
- Появляется inline редактор с текстовым полем
- Редактируем текст
- Нажимаем кнопку **«Сохранить»** или `Ctrl+Enter` для сохранения
- Нажимаем **«Отмена»** или `Esc` для отмены изменений
- Изменения автоматически сохраняются в базе данных
- Появляется уведомление «Изменения сохранены ✓»

### 4. Выход из режима редактирования

- Нажимаем кнопку **«Готово»** в хедере
- Режим редактирования отключается
- Иконки карандаша исчезают
- Сеанс авторизации сохраняется в браузере (localStorage)

## Редактируемые элементы

На странице доступны для редактирования следующие текстовые элементы:

### Hero секция
- Badge текст
- Основной заголовок
- Подзаголовок
- Статистика (цифры и подписи)

### Problems секция
- Заголовок секции
- Подзаголовок
- Заголовки и описания всех карточек проблем
- Финальный текст-мост

### About секция
- Метка секции
- Имя преподавателя
- Tagline
- Основные текстовые параграфы
- Цитата
- Статистика с цифрами

### Formats секция
- Метка и заголовок секции
- Подзаголовок
- Для каждого формата:
  - Название формата
  - Описание
  - Пункты списка
  - Цена

### Process секция
- Метка и заголовок
- Для каждого из 4 шагов:
  - Название шага
  - Описание

## Технические детали

### Хранилище данных
- Все изменения сохраняются в файл `admin-data.json` на сервере
- База данных JSON — простая и надёжная
- Изменения видны всем посетителям сайта сразу же

### API Endpoints
- `GET /api/texts` — получить все редактируемые текс
- `POST /api/texts` — сохранить изменения (требует пароль)
- `POST /api/auth` — проверить пароль администратора

### Безопасность
- Пароль отправляется на сервер в открытом виде (используется HTTPS в production)
- Администратор не сохраняется в БД — нет отслеживания сеансов
- Сеанс хранится в браузере (localStorage) — при очистке cookies сеанс теряется

## Возможные проблемы

### Кнопка не видна в хедере
→ Проверьте, что `admin.js` загружен в конце `index.html`

### Модальное окно не появляется
→ Убедитесь, что JavaScript включен в браузере
→ Проверьте консоль браузера на ошибки

### Изменения не сохраняются
→ Проверьте, что сервер запущен на `localhost:3000`
→ Убедитесь, что пароль правильный
→ Проверьте права доступа на записьв папку проекта

### Иконки карандаша не видны в режиме редактирования
→ Может быть проблема с CSS
→ Попробуйте обновить страницу (F5)
→ Проверьте, что `styles.css` загружен полностью
